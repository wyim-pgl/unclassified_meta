What the feature does: Centrifuger per-read output can list several taxIDs per read (-k > 1). `unclassified-meta taxa-table --per-read --assign em --imputations M` (run as python -m unclassified_meta.cli) shares such reads by maximum likelihood (expected counts) and writes M integer imputation tables drawn from the posterior; `da --imputations` fits ANCOM-BC2 on each table and combines them with Rubin's rules (mi_results.tsv). The default `--assign lca` gives an ambiguous read the lowest common ancestor.

Question to answer with numbers: compared with LCA (and with the EM expected-count table alone), does EM + multiple imputation give (a) unbiased log-fold-change estimates for taxa whose reads are often ambiguous, (b) a false-positive rate at or below nominal under the null, (c) confidence-interval coverage near 95% for the true group effect, and (d) power?
